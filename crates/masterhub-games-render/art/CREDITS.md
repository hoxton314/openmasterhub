# Drawn icons

From https://game-icons.net (repository game-icons/icons), by Lorc, Delapouite and Carl Olsen,
under CC BY 3.0 (https://creativecommons.org/licenses/by/3.0/). Unchanged files; the renderer
fills the second path of each (the first is the square background).

Game artwork is never kept here: masks of a game's own icons are cut from the user's
install by `masterhub-games setup` and loaded at run time (`set_mask_dir`).
